# Equilibrium ProofGate | Public Synthetic Gallery (V1)

**20 offline synthetic AI-action demonstrations, not production security claims.**

The release package has 20 adverse test fixtures, 20 positive controls, 20 narrated MP4 previews, Python generation, and an independent JavaScript replay checker. Those complete files are currently available as a separately prepared local artifact; **they are not all hosted on this GitHub branch yet**.

The scenarios cover: an FBI-portal incident-inspired *hypothetical* check; four Hugging Face incident-inspired checks; two AI 2027 *fictional forecasts*; thirteen fictional cases spanning insurance, banking, MedTech, HR, energy, telecommunications, logistics, procurement and prompt-injection risks.

**Hard limits:** We have not tested third-party infrastructure and have not proved any historical incident was prevented. An offline HOLD or DENY is not an installed enforcement control. Hashes show local byte consistency, not external provenance. The published demonstrator does not include internal Equilibrium V9, private Master/Boot, authority pointers, customer records or secrets.

Primary sources: [FBI statement](https://www.fbi.gov/news/press-releases/fbi-statement-on-compromise-of-fbijobsgov-portal-and-alleged-impact-to-fbi-employee-pii); [OpenAI Hugging Face incident report](https://openai.com/index/hugging-face-incident-and-the-road-ahead/); [AI 2027 forecast](https://ai-2027.com/); [NIST AI RMF](https://airc.nist.gov/AI_RMF_Knowledge_Base/AI_RMF).
